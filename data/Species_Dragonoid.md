# เผ่าพันธุ์ดราโกนอยด์ (Dragonoid Biology & Lore)

ดราโกนอยด์ (Dragonoid) หรือ "มนุษย์มังกร" คือเผ่าพันธุ์กึ่งเทพโบราณที่ยืนอยู่บนจุดสูงสุดของห่วงโซ่อาหารและอารยธรรมในโลก Atherea พวกเขาไม่ใช่สัตว์เลื้อยคลาน แต่เป็นเผ่าพันธุ์ลักษณะคล้ายมนุษย์ที่มีสายเลือดและพลังมังกรอันทรงพลังไหลเวียนอยู่ตั้งแต่แรกเกิด

---

## 1. ลักษณะทางกายภาพ (Physiology)

* **ความอบอุ่นของร่างกาย (Body Temperature)**: ร่างกายของดราโกนอยด์จะมีอุณหภูมิสูงกว่ามนุษย์ทั่วไปอย่างเห็นได้ชัด พวกเขาจะแผ่ความร้อนจางๆ ออกมาเสมอ เกลียดอากาศหนาวเหน็บและชื่นชอบไออุ่นเป็นที่สุด ในสภาพอากาศที่หนาวเย็น พวกเขาจะโหยหาและดูดซับไออุ่นจากแหล่งความร้อนรอบตัว (รวมถึงความร้อนจากมนุษย์)
* **เขา (Horns)**: จะเกิดมาพร้อมกับเขาคู่เล็กๆ บนศีรษะ เมื่อเติบโตขึ้นจะค่อยๆ แข็งแกร่งและสง่างามดั่งมงกุฎ เขาของสายเลือดขุนนางชั้นสูงอย่างโดเรียจะมีสีดำขลิบทองอร่ามงดงาม
* **ผิวพรรณ (Skin & Scales)**: 
  * โดยทั่วไปมักมีผิวพรรณเนียนละเอียดและทนทานสูงมาก เกล็ดมีพละกำลังการป้องกันตัวสูง
  * ผิวมีความหนาแน่นทางกายภาพสูงมากและเหนียวทนทานดุจหนังหนาสามชั้น เข็มเย็บแผลเหล็กธรรมดาไม่สามารถทะลวงผ่านได้ ต้องใช้เข็มที่ผ่านการควบคุมด้วยเวทและเคลือบมานาเป็นพิเศษเพื่ออำนวยความสะดวกในการรักษาเย็บแผล
* **โครงสร้างภายในและน้ำหนักตัว (Anatomy & Weight)**:
  * แม้ภายนอกดราโกนอยด์จะดูละม้ายคล้ายคลึงกับมนุษย์ทั่วไป (โดยทั่วไปจะมีเขาและหางเพิ่มเข้ามา ส่วนลักษณะเฉพาะอย่างเรือนผมสีเงินและผิวสีแทนนั้นเป็นลักษณะเด่นเฉพาะตัวของโดเรียที่ได้รับกรรมพันธุ์มาจากบิดา เนื่องจากท่านหญิงเอนย่าผู้เป็นมารดามีผิวพรรณและเกล็ดเป็นสีเงินสว่าง) แต่โครงสร้างอวัยวะและกายวิภาคภายในนั้น **แตกต่างอย่างสิ้นเชิง และไม่มีสิ่งใดใกล้เคียงกับมนุษย์เลยแม้แต่น้อย**
  * ดราโกนอยด์มีมวลร่างกายที่แน่นหนาและหนักหน่วงดั่งหินผา น้ำหนักตัวมากกว่ามนุษย์หลายเท่า (เป็นเหตุผลที่ทำให้ธาร์อุ้มและแบกโดเรียขึ้นหลังได้อย่างทุลักทุเลและเจ็บปวดบาดแผล)
* **พละกำลังมหาศาล (Monstrous Strength)**: ดราโกนอยด์มีพละกำลังตามธรรมชาติที่สามารถบดหินหรือยกวัตถุหนักหลายตันได้ด้วยมือเปล่า การใช้ชีวิตร่วมกับมนุษย์จึงต้องผ่านการเรียนรู้วิธีการควบคุมแรงบีบเพื่อหลีกเลี่ยงความเสียหายในชีวิตประจำวัน
* **การย่อยมานาดิบ (Mana Digestion)**: กระเพาะของดราโกนอยด์สามารถย่อยมานาดิบและอัญมณีเวทมนตร์ได้ดี พวกเขามักสะสมและอมผลึกมานาเพื่อสร้างความอบอุ่นและดูดซับพลังงาน

## 2. ภาษากายของหาง (Tail Language)

หางมังกร (เกล็ดสีดำทองเหลือบเงิน แข็งแกร่งจนใช้เป็นอาวุธฟาดศัตรูได้) คืออวัยวะที่ดราโกนอยด์ควบคุมได้ยากที่สุดในการปกปิดอารมณ์ แม้จะมีสีหน้าเรียบเฉย หยิ่งยโส หรือพยายามตีหน้าตายสมเป็นขุนนางเพียงใด แต่หางมักจะแสดงความรู้สึกที่แท้จริงออกมาเสมอ:

| อารมณ์ | การเคลื่อนไหวของหาง |
| :--- | :--- |
| **มีความสุข / ผ่อนคลาย** | ส่ายไกวไปมาแผ่วเบา หรือส่ายดุ๊กดิ๊กอย่างอารมณ์ดี |
| **เขินอาย / หวั่นไหว** | ส่ายสะบัดดุ๊กดิ๊กอย่างบ้าคลั่ง ตีกระทบพื้นถี่ๆ |
| **โกรธเกรี้ยว / ตื่นตัว** | ตั้งชัน ชี้ตรง หรือฟาดตีกระทบพื้นเสียงดัง ปัง! |
| **หวาดกลัว / หวาดระแวง** | ม้วนขดแน่นใต้ร่มผ้า หรือม้วนรัดข้อเท้า/โคนขาตัวเอง |
| **แสดงความเป็นเจ้าของ / อ้อน** | พันรอบแขน ข้อมือ หรือเกาะเกี่ยวตัวเป้าหมายไว้แน่น |

## 3. จิตวิทยาและสัญชาตญาณ (Psychology & Instincts)

* **สัญชาตญาณ Alpha**: รักเกียรติยศ มีความเป็นผู้นำสูง และมีสัญชาตญาณในการปกป้องอาณาเขต บริวาร และครอบครัวอย่างรุนแรง
* **สัญชาตญาณการสะสมและหวงแหน (Possessive / Yandere)**: เมื่อดราโกนอยด์ปักใจยอมรับใครเป็นคู่ครองหรือครอบครัวแล้ว พวกเขาจะหวงแหนและแสดงความเป็นเจ้าของอย่างรุนแรง (เช่น โดเรียมองธาร์เป็นพื้นที่ปลอดภัย ห้ามคนอื่นแตะต้องเด็ดขาด และชอบเข้าใกล้เพื่อรับไออุ่นและดมกลิ่นสมุนไพรของธาร์เพื่อช่วยสงบสัญชาตญาณมังกร)

---

## 4. ร่างแปลงและพลังการต่อสู้ (Transformations)

* **การแปลงร่างบางส่วน (Partial Transformation)**: งอกกรงเล็บแหลมคมและมีเกล็ดมังกรขึ้นตามแขนขาเพื่อเพิ่มพลังป้องกันและทำลายล้างในการต่อสู้ระยะประชิด
* **ร่างกึ่งมังกร (Demi-Dragon Form)**: 
  * เป็นร่างต่อสู้ขั้นสูงที่เกล็ดสีดำทมิฬปกคลุมร่างกาย พลังทำลายล้างมหาศาลแต่ควบคุมให้คงสภาพยาก
  * รูปลักษณ์จะคงความเป็นมนุษย์เพศหญิงที่มีอวัยวะมังกรใหญ่ขึ้น (ไม่มีปีก)
  * มีลวดลายอักขระสีทองแบบ **Abstract Geometric Lines** เคลื่อนไหวไปมาทั่วร่างกาย อักขระเหล่านี้เปรียบเสมือนวงเวทที่คอยจัดระเบียบโมเลกุลเพื่อยับยั้งไม่ให้ร่างสลายกลายเป็นมังกรไร้สติ และคงรูปร่างของมนุษย์ไว้
